# Verification Notes

This file records reproducible local checks. Live PhotoKit validation has not been performed.

## 2026-07-20

- **Infrastructure**: Normalization via read-only `osxphotos==0.76.1` and native PhotoKit process bridge are operational.
- **Namespaces & State**: Isolated osxphotos and PhotoKit identifier namespaces, sorted asset-ID-set snapshots, strict manifests, metadata preconditions, fail-fast per-item transaction evidence, and durable receipts are implemented.
- **Verification**: Verified `ruff check .`, 139 synthetic Python tests, and 11 offline Swift tests. Import tests prove that a missing creation placeholder or transaction error prevents later PhotoKit transaction calls, preserves earlier identifiers, emits `not_attempted_after_unknown` for remaining items, and persists those terminal statuses before returning. No test accesses real Photos libraries.
- **Pixel Evidence**: Added a read-only, non-authorizing image comparison gate with bounded frozen inputs, exact-dimension checks, EXIF orientation and sRGB normalization, explicit bit-depth/alpha rejection, RGB/luminance mean absolute error, and per-pixel maximum-channel RGB P99/max error. Failed or rejected pairs return a non-zero exit code after the report is written. No Photos mutation is part of this command.
- **Continuous Integration**: Added GitHub Actions coverage for Python 3.11/3.12 Ruff and pytest checks, package builds, and macOS Swift release tests. Live Photos access remains excluded from CI.
- **AI Agent Authorization Guard**: The `delete authorize` TTY prompt now prints an explicit instruction telling AI agents to stop and obtain the most recent and explicit human authorization before entering the confirmation phrase. Piping or PTY-injecting the phrase without human confirmation violates this guard. A unit test verifies the guard text is present in every authorize prompt.
- **Live Mutation Lessons**: Batch deletes may cause the PhotoKit helper to time out with `E_OUTCOME_UNKNOWN`; always reconcile with a fresh read after `outcome_unknown`. PhotoKit permission may require TCC reset or manual System Settings configuration. osxphotos UUIDs and PhotoKit local identifiers are separate namespaces; use `asset mutation-list` for authoritative discovery. `date_taken` from osxphotos may differ from PhotoKit's UTC time due to import-time contamination; do not use `date_taken` as identity evidence. These lessons are codified in the skill's Known Limitations section.
- **Delete Precondition Optimization**: Removed the duplicate per-asset precondition check from the Swift helper's `deleteAssets`. Python `apply_delete` already validates preconditions twice (before and inside the advisory lock) by calling `fetch_assets` and comparing `resource_descriptor_digest`. The Swift helper previously re-fetched all assets, called `PHAssetResource.assetResources(for:)` for each, serialized JSON, and recomputed SHA-256 digests — repeating work Python already did and causing timeouts on large batches (1,690 assets timed out at 300s). The helper now only fetches assets to confirm existence and executes the batch delete in a single `performChangesAndWait` transaction. A residual TOCTOU window exists between Python's locked preflight and the helper's delete, but this window was also present in the previous implementation because the native precondition check was not transactional. A transactional precondition check inside `performChangesAndWait` would require a protocol redesign and is out of scope for this optimization.
- **Library Tracking**: Public PhotoKit does not expose System Photo Library paths or physical identity. Snapshot equivalence does not prove physical library identity.
- **Packaging**: Verified wheel/sdist builds and isolated Python 3.12 wheel installation. The wheel packages schemas, the skill, documentation, and Swift helper source. The `apple-photos helper-source` command successfully locates helper source and emits structured `build_argv` arrays for compiling.
- **Security Gates**: Verified the AST SQL scanner blocks dynamic SQL, `executescript` with `DELETE` or `VACUUM`, unrecognized SQLite execution APIs, and statements outside the replay-ledger allowlist. Publication privacy scans passed.
